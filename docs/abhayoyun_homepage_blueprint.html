"The events section is where browsers become buyers. Every element — scarcity, location, date — creates urgency without pressure. The design must feel sacred, not salesy."
Scarcity system
Always show remaining spots. When 5 or fewer: amber "X Spots Left" badge. When full: grey "Waitlist" button. This is the #1 conversion driver.
Filter UX
Category pills animate cards in/out. Smooth JS filter — no page reload. Helps repeat visitors find what they want fast.
Past events
Below active events: "Past Ceremonies" in a lighter grid — builds proof of track record and globe-spanning work.
CTA copy Never "Buy Ticket" — use "Apply", "Reserve Your Place", "Join the Circle", "Request an Invitation"
Featured card Always one featured/hero event at top spanning full width. Rotating highlight. Most impactful upcoming event.
Location poetry "Altai Mountains, Russia" hits differently than "Russia". Location names are part of the mystique.
Price display "From $2,800" — never the full price upfront. Leads with "From". Keeps aspirational energy. Full investment on detail page.
